# Basic Calculator
### Project Overview
This project is a Calculator application built using HTML, CSS, and JavaScript. It simulates a basic calculator that can perform arithmetic operations like addition, subtraction, multiplication, and division. The app has a clean user interface, suitable for anyone who wants to perform basic calculations right in their browser.
### Features
- Basic Arithmetic Operations: Supports addition, subtraction, multiplication, and division.
- Clear Display: Users can reset the calculator by clearing the display.
- Keyboard Support: The calculator can also be operated using a physical keyboard.
- Responsive Design: The calculator adjusts its layout based on the device's screen size for a better user experience.
- Error Handling: Handles edge cases, such as division by zero, with an appropriate error message.
### Technologies Used
- HTML: Provides the structure of the calculator layout.
- CSS: Styles the calculator, making it responsive and visually appealing.
- JavaScript: Adds functionality to handle calculations and user interactions.
### Installation
1. Clone the repository:
   git clone https://github.com/your-username/calculator.git

2. Navigate to the project directory:
   cd calculator
3. Open the project: Open index.html in your preferred browser.

### How to Use
1. Basic Usage:

- Click on the number buttons to input numbers.
- Use the arithmetic operator buttons (+, -, ×, ÷) for calculations.
- Click the = button to get the result.

2. Clear Display:

- Press the AC button to reset the calculator and clear the display.

3. Keyboard Support:

- You can also use your keyboard for input. The calculator supports number keys and the following operators:
  - '+' for addition
  - '-' for subtraction
  - '*' for multiplication
  - / for division
  - = to calculate
  - DEL to delete a single character.

### File Details
- index.html:
  - Contains the HTML structure for the calculator, including the display screen, buttons, and layout.
- style.css:
  - Styles the calculator interface for a sleek and user-friendly experience.
  - Includes responsiveness for different screen sizes (desktop, tablet, mobile).
- script.js:
  - Handles the core functionality of the calculator.
  - Includes event listeners for button clicks and keyboard input.
  - Manages arithmetic calculations and updates the display dynamically.
